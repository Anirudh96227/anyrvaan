This is ten short films, and each one rebuilds an old computer exactly as it looked on screen — the Commodore 64, MS-DOS, Windows 95, the first iPhone, and six more in between. Here's the part that matters: none of it is a screenshot or an old recording. Every pixel was drawn again from scratch, to match what these machines really looked like when they were new.

I did it that way because of something I only half-believed until I checked it against myself: I don't remember these machines as well as I think, and neither do you. I remember the *idea* of Windows 95 — the teal background, the Start button. I'd forgotten the little grey banner down the side of the Start menu, the exact way the buttons sat raised off the screen, the red counter in Minesweeper. Build it from memory and you get something that feels almost right and is wrong in a dozen tiny ways. Almost-right is worse than obviously fake, because anyone who was there feels something's off without being able to say what.

So I chased the small stuff most people never noticed but would miss without knowing it. The Commodore 64 boots up saying it has exactly 38,911 bytes free, then sits loading from tape for an uncomfortably long time — because it truly did, and speeding it up to be "watchable" would give the whole game away. The 1997 web page has a visitor counter that ticks up as you watch, a spinning UNDER CONSTRUCTION sign, a little MIDI tune. Get enough of these right and the memory snaps back into focus. There's a specific relief in that snap of recognition — oh, *that's* exactly what it looked like — and it only shows up when I didn't fake it.

The films are also strung together on purpose. Each one opens like a title card and ends on a blinking light that hands straight off to the next machine, so twenty-five years of computers play as one continuous run rather than ten separate clips. The care that went into looking things up instead of trusting memory is the subject of [I rebuilt old computers and learned my memory was lying](/blog/ui-archaeology/), and the wider collection of screen looks this pulls from is [a field guide to app animations](/work/ui-animation-atlas/).
